# Drop - Open Source Game Distribution for Self-Hosted Libraries

## Private Game Library Overview

Download Drop OSS to host, organize, and deliver DRM-free PC titles from your own private library with a clean web interface, secure access, and fast installs. Pair it with Drop desktop client for smooth downloads, launching, and updates across your collection.

Drop is an open-source game distribution platform for hosting DRM-free titles, managing access, and launching games from a desktop client. Drop game distribution is designed for players, families, small studios, and private communities that want a polished Drop game platform without depending on a commercial storefront. With Drop OSS, a self-managed catalog can stay organized, searchable, and ready for downloads from a browser or the Drop desktop client.
